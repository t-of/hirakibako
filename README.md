# ひらきばこ — 開いた箱の六面をそろえる

箱を開いて平らにした図の上で、面を回して六つの面の色をそろえるパズル。まん中の面を囲む四つの面と、外をぐるりと囲む裏の面がつながって動く。2×2 と 3×3。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/hirakibako/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

箱を開いて平らにした図で遊ぶ。まん中が前の面、その上下左右が上・下・左・右の面、全体を囲む大きな輪が裏の面。

1. 面をタップすると、その面が右回りに 90° 回る。面の上で指をぐるっとなぞると、その向きに回る。
2. 面を回すと、となりの面の色も一緒に動く（箱を開いた図なので、辺でつながっている）。
3. 六つの面がそれぞれ 1 色になったらクリア。

- 裏の面は、大きな輪の上を指でなぞるか、右下のボタンで回す。
- 大きさは 2×2 と 3×3、段階は やさしい（3 回崩す）/ ふつう（6 回）/ 本気（2×2 は 11 回、3×3 は 25 回）。
- 「1 手もどす」「はじめから」（同じ形から）「べつの形」（崩し直す）。
- 記録は大きさ × 段階ごとの、そろえた手数の最少。端末の中にだけ保存する。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 回し方・崩し方・クリア判定の確かめ
```

- `game.js`: 盤とルール（描画から切り離してある）。マスは 6n² 個で、面を回すのは「どのマスがどこへ行くか」の表。表は立体の位置を 90° 回して作る。
- `main.js`: 画面・指の操作・音。
